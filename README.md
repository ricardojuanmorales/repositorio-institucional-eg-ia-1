# Proyecto_RIB_EG_IA

**Repositorio Institucional de Colecciones Bibliográficas en Educación General e Inteligencia Artificial**

**Versión estructural:** v0.3  
**Fecha:** 2026-05-07  
**Nivel operativo:** N3 en estabilización  
**Horizonte:** Full N4 pendiente hasta lograr N3 operacional  
**Modalidad:** planificación estratégica, sistémica, holística y transdisciplinaria

---

## Propósito

Este repositorio organiza el trabajo del Proyecto_RIB_EG_IA como sistema institucional de conocimiento. Integra bibliografía generalizada, bibliografía anotada, taxonomía, matriz maestra, diseño instruccional universal, colaboración, evaluación, publicación WordPress, documentación activa y mantenimiento.

## Principio operativo

El proyecto comienza organizado desde el principio. La estructura completa de cartapacios existe aunque algunos espacios permanezcan vacíos hasta que el flujo de trabajo los requiera.

## Entornos previstos

| Entorno | Función |
|---|---|
| Cartapacio local | Taller de trabajo editable |
| GitHub | Versionado, historial, issues, releases y colaboración |
| Obsidian | Segundo cerebro, mapas de navegación, enlaces y documentación viva |
