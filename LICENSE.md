# Licencia

Pendiente de definir.

## Recomendación inicial

Mientras se define la política institucional, usar este archivo como marcador.

Opciones futuras:

- Creative Commons Attribution 4.0 International, para documentación pública.
- Creative Commons Attribution-NonCommercial 4.0 International, si se desea limitar uso comercial.
- Licencia institucional interna, si el repositorio aún no será público.

## Nota

No publicar materiales con derechos de terceros sin revisión de licencia, permiso o uso justo aplicable.
