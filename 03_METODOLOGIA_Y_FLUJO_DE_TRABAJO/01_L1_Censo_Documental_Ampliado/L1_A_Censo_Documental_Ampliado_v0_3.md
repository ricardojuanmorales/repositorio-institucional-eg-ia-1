**Proyecto:** Proyecto_RIB_EG_IA

**Estado:** Borrador operativo inicial

## Objetivo

Mapear el máximo de referencias disponibles de bibliografía generalizada y bibliografía anotada para comprender la complejidad del corpus antes de seleccionar pilotos.

## Fuentes de entrada

| Fuente | Tipo | Estado |
|---|---|---|
| Bibliografía generalizada base consolidada | Documento histórico | Pendiente de importar |
| Bibliografía anotada BA-001 a BA-060 | Repositorio anotado | Pendiente de importar |
| Paquete v0.1 | Histórico | Pendiente |
| Paquete v0.2 | Base operativa | Pendiente |
| Herramientas vivas | Recursos digitales | Pendiente de revisar |

## Tareas L1-A

1. Inventariar todas las referencias disponibles.
2. Asignar identificadores únicos.
3. Detectar duplicados y equivalencias.
4. Separar bibliografía generalizada, anotada, temática, herramientas vivas y fuentes no verificadas.
5. Marcar estado de completitud.
6. Preparar insumos para L1-B taxonomía sistémica.

## Criterio de cierre

L1-A cierra cuando existe una matriz inicial de inventario suficientemente amplia para alimentar la taxonomía sistémica v0.3.
