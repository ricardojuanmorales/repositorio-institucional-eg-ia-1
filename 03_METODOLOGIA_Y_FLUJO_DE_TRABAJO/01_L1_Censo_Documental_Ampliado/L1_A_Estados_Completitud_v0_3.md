---

| Estado | Definición | Acción |
|---|---|---|
| Completa | Tiene referencia, autoría, año, título, tipo y ubicación curricular | Clasificar |
| Parcial | Le falta algún metadato importante | Completar |
| Pendiente de verificación | Requiere confirmar existencia o enlace | Verificar |
| Duplicada | Coincide con otra fuente | Resolver |
| Herramienta viva | Puede cambiar con frecuencia | Revisar periódicamente |
| Temática complementaria | No pertenece al núcleo general | Mover a anexo temático |
| Lista para piloto | Puede usarse para ficha, colección, DIU/DUA o WordPress | Seleccionar |
