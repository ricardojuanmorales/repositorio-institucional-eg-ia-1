## Criterios mínimos

Una fuente se considera verificable cuando se puede confirmar:

- existencia;
- autoría;
- año;
- título;
- editorial, revista, institución o plataforma;
- DOI, URL, repositorio o ubicación;
- tipo de fuente;
- acceso o licencia;
- pertinencia curricular.

## Estados

| Estado | Uso |
|---|---|
| Verificada | Puede incorporarse formalmente |
| Parcialmente verificada | Puede rastrearse, pero requiere completar metadatos |
| No verificada | No debe citarse formalmente |
| Herramienta viva | Debe revisarse periódicamente |
| Caso local / institucional | Puede usarse como contexto si se identifica correctamente |
